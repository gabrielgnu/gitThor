# Contribuir a GitThor

El repositorio es público y el código se distribuye bajo licencia MIT. Podés descargarlo y modificar tu propia copia o fork. El acceso público no concede permisos de escritura sobre el repositorio de gabrielgnu.

## Proponer una mejora

1. Abrí un issue con el problema, el resultado esperado y los pasos para reproducirlo.
2. Creá un fork y una rama para tu cambio.
3. Instalá dependencias con `npm ci` y ejecutá `npm run check` y `npm test`. Si cambia la interfaz, ejecutá también `npm run test:ui`.
4. Enviá un pull request indicando el comportamiento que cambia y las pruebas ejecutadas.

La revisión y aceptación corresponden al mantenedor, @gabrielgnu. Los pull requests no modifican el proyecto original hasta que se incorporan con los permisos correspondientes. No solicites ni publiques tokens, contraseñas, datos de clientes ni repositorios privados como fixtures.
